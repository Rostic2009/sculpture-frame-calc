# Каркас скульптури — розрахунок

Браузерний застосунок для розрахунку сталевого каркаса скульптури з квадратних гнутозварних труб:
вітер, сніг, сейсміка за ДБН, просторовий МСЕ (1-й/2-й порядок), перевірки труб за ДБН В.2.6-198 і EN 1993-1-1,
опорні вузли (пластина, шов, анкери за EN 1993-1-8 / EN 1992-4), фундамент (ДБН В.2.1-10), специфікація, вартість і розрахункова записка.

Працює повністю в браузері: без сервера, без API і платних токенів.

## Запуск
- Онлайн: GitHub Pages цього репозиторію (Settings → Pages → Source: GitHub Actions).
- Локально: відкрийте `index.html` у браузері.

## Обмеження
Результат без підтверджених аеродинамічних коефіцієнтів має статус «попередній». Табличні значення зі статусом «звірити»
потрібно звірити з офіційним текстом норм. З 01.07.2026 діє нова редакція ДБН з сейсміки — коефіцієнти сейсмічного модуля редагуються.
Розрахунок не замінює перевірки відповідальним інженером-конструктором.

## Геометрія для розрахунку

- **Картинка — лише ескіз:** з неї в проєкт переходить поділ на частини (назви, тип) і ідея схеми каркаса; розміри з картинки в розрахунок не потрапляють. Перевіряється узгодженість видів (спереду / збоку / зверху).
- **3D-модель (STL/OBJ)** — джерело розмірів: перерізи по висоті (площа, периметр, центр, ядро вписується із зазором), маса і вітер по смугах висоти, пропозиція ядра й поясів, розкрій обшивки на нумеровані сегменти листа.
- **Шлейф (лежача частина):** просторова тригранна ферма по гребеню з поперечними рамами й власними опорами (проміжні шарнірні, крайня рухома), секції Ш1, Ш2…; фундаменти — окремі подушки, подушки з рандбалками або спільна плита.
