# Каркас скульптури — розширення SketchUp

Розрахунок сталевого каркаса скульптури за ДБН прямо по 3D-моделі SketchUp. Розрахункове ядро — той самий застосунок, що й на сайті (без змін); розширення додає міст між моделлю і розрахунком.

**Потрібно:** SketchUp Pro 2021 або новіший (Windows або Mac). Веб-версія SketchUp розширень не підтримує.

## Встановлення
1. Завантажте `sculpture_frame.rbz`: https://rostic2009.github.io/sculpture-frame-calc/dist/sculpture_frame.rbz
2. SketchUp → **Extensions → Extension Manager → Install Extension…** → оберіть файл → **Yes**.
3. Якщо SketchUp попереджає про непідписане розширення: в Extension Manager → ⚙ → **Loading Policy: Unrestricted**, перезапустіть SketchUp і встановіть ще раз.
4. З'являться меню **Extensions → Каркас скульптури** і панель інструментів «Каркас скульптури».

## Підготовка моделі
| Що | Як у SketchUp |
|---|---|
| Початок координат | Центр низу каркаса-ядра на верху постаменту; вісь Z — вгору (Tools → Axes) |
| Частини скульптури | Кожна частина — окрема **група або компонент** з назвою: «Тулуб і плащ», «Голова», «Права рука», «Шлейф мантії» |
| Тип частини | За назвою: тулуб/плащ/постать → по висоті ядра; шлейф/мантія → шлейф; решта → консоль (можна змінити у вікні) |
| Додаткові стрижні каркаса | Лінії на тезі **«Каркас»**; переріз — у назві тегу: «Каркас □80×4», «Каркас 60x3». Кінці на z = 0 — опори |
| Гребінь шлейфу | Полілінія від плечей до землі на тезі **«Гребінь <назва частини>»**, напр. «Гребінь Шлейф мантії» |

## Робота
1. **Відкрити розрахунок** — вікно застосунку з панеллю SketchUp унизу праворуч.
2. Виділіть групи частин → **Вибране → частини**: площа поверхні, центр, проєкції під кожним кутом вітру, сніг — з моделі, у метрах.
3. **Лінії «Каркас»** і **Гребінь** — за потреби.
4. Задайте майданчик, ґрунти, перерізи; **Розрахувати**.
5. **Каркас → у модель**: група «Каркас (розрахунок)» — труби справжнього профілю, колір за запасом (U) або за секціями, марки, опорні плити, анкери, фундаменти; кожна секція на своєму тезі «Каркас: Я1», «Каркас: Ш1»…
6. PDF-звіт і файли зберігаються через діалог збереження SketchUp.

Проєкт розрахунку зберігається **в самому файлі .skp** і відкривається разом із моделлю.

## Розробка
- `src/` — код розширення (Ruby + міст `bridge.js`); застосунок сайту копіюється під час збирання.
- `python3 build_rbz.py` → `../dist/sculpture_frame.rbz`.
- Тести: `ruby test/geom_util_test.rb`, `ruby test/main_test.rb` (імітація SketchUp API).
